# Safety Inspection: แผนตรวจ ปจ.2 (Requirements)

## Overview
ลูกค้า (พี่มิก) อยากให้การตรวจ ปจ.2 ทำงานเป็น **"แผนการตรวจ"**
เป้าหมายตอนนี้: ทำ prototype ให้ลูกค้าลองเล่น เพื่อ confirm spec, requirement และ scope

### Flow ทั้งหมดจากลูกค้า
สร้างแผน > เลือกยานพาหนะเข้าแผน > อนุมัติแผน > สร้างแผนเดินทางตามพื้นที่ (จ้าง) > อนุมัติแผนเดินทาง > noti แจ้งหน่วยงานรับทราบแผนเดินทาง > บันทึกผลตรวจรายคัน > noti แจ้งหน่วยงานรับทราบผล > ทะเบียน ปจ.2 อัปเดตเอง > ขออนุมัติปิดงาน > ปิดแผน

รายละเอียดของแต่ละขั้น (ตามที่ลูกค้าเขียนมา):
1. **สร้างแผน**: กำหนดรอบการตรวจเป็นช่วงเดือน (จากเดือนไหนถึงเดือนไหน) ไม่ใช่ไตรมาส และไม่มีอะไหล่
2. **เลือกยานพาหนะเข้าแผน**
   - กรองตาม สังกัด / ครบกำหนดตรวจ / วาระ / ประเภทยานพาหนะ
   - มีคอลัมน์สถานะยานพาหนะ และผู้ครอบครอง/เบอร์ติดต่อ
   - ยานพาหนะที่อยู่ในแผน ปจ.2 อื่นที่ยังไม่ปิด เลือกไม่ได้ (ห้ามซ้อนแผน)
3. **แผนเดินทาง**
   - ผูกกับแผนการตรวจ สร้างตามพื้นที่ที่จะไปตรวจ และสร้างได้หลายแผน
   - รูปแบบดำเนินการเป็น "จ้างดำเนินการ"
   - อนุมัติแล้วส่ง noti แจ้ง กรย. และผู้ดูแลยานพาหนะ
4. **บันทึกผลตรวจรายคัน** (หน่วยงานผู้สร้างแผน หรือผู้รับจ้าง)
   - ผล: ผ่าน / ไม่ผ่าน / ระงับ / ตรวจไม่ได้
   - กรอกวันที่ตรวจ + ค่าจ้างตรวจรายคัน + แนบเอกสาร ปจ.2
   - ไม่ผ่านหรือระงับ: ส่ง noti ให้เปิดงานซ่อม
   - ตรวจไม่ได้: ต้องระบุเหตุผล + แนบหนังสือรับรองจากผู้แทนหน่วยงาน และคงวันครบกำหนดเดิม
   - บันทึกแล้ว noti แจ้งผลถึงผู้ดูแลยานพาหนะเอง ไม่ต้องกดรับทราบ
5. **ปิดงานแผน**
   - เงื่อนไข: ยานพาหนะที่ไม่มีในแผนเดินทางเป็น 0 คัน และบันทึกผลครบทุกคัน
   - ขั้นตอน: กดขออนุมัติปิดงาน > เลือกผู้อนุมัติ > รออนุมัติ > อนุมัติแล้วปิดแผน
6. **ทะเบียน ปจ.2**
   - อัปเดตวันตรวจล่าสุด ผล และวันครบกำหนดถัดไปให้อัตโนมัติ
   - ปุ่มอัปโหลดในทะเบียนแสดงเฉพาะยานพาหนะที่ไม่อยู่ในแผน ปจ.2 ใด (กรณีตรวจนอกแผน ตรวจรายคัน หรือไม่ได้สร้างแผน)

## ผู้ใช้งานระบบ (Roles)
| บทบาท | สิทธิ์ |

## Flow ปัจจุบัน (branch `revamp-flow-create-plan` · 20 พ.ย. 2569)
1. กบค. สร้างแผน: ข้อมูลแผน + เลือกยานพาหนะเข้าแผน (ไม่มีผู้รับจ้าง ไม่มีค่าจ้าง ไม่มีไตรมาส) → ส่งอนุมัติ
2. หัวหน้า กบค. อนุมัติแผน (หรือส่งกลับแก้ไข)
3. กบค. สร้างแผนเดินทางจากหน้ารายละเอียดแผน (แทนหน้าไตรมาสของงานบำรุงรักษา) ได้หลายแผน
   - ชื่อแผนเดินทาง · ช่วงวันทำงาน · ผู้รับจ้าง + เบอร์ + เลขที่สัญญา (ถ้ามี)
   - เลือกยานพาหนะจากคันในแผนที่ยังไม่อยู่ในแผนเดินทางใด (1 คัน = 1 แผนเดินทาง)
   - รายคัน: สถานที่ตรวจ · ผู้ดูแลยานพาหนะ/เบอร์ · วันดำเนินการ (ค่าเริ่มต้น = สำนักงานสังกัด · ผู้ครอบครอง · ช่วงวันทำงาน) · ค่าจ้างตรวจ (ต้องครบทุกคัน)
   - ~~สร้างแล้วใช้ได้ทันที~~ → **ส่งให้หัวหน้า กบค. อนุมัติ** · อนุมัติแล้วแจ้งผู้รับจ้าง กรย. และผู้ดูแลยานพาหนะ · ส่งกลับ = กบค. แก้แล้วส่งใหม่
4. ผู้รับจ้างบันทึกผลรายคันใน popup → ส่งอนุมัติ → กบค. อนุมัติ/ส่งกลับ
5. ทุกคันในแผนเดินทางอนุมัติแล้ว → ผู้รับจ้างส่งอนุมัติปิดงาน → กบค. อนุมัติปิดงาน หรือส่งกลับ
6. ไม่มีปิดแผนหลัก · ทุกคันของแผนอยู่ในแผนเดินทางที่ปิดงานแล้ว → แผนเป็น "เสร็จสิ้น" เอง
- **สถานะแผน:** รออนุมัติ · ส่งกลับแก้ไข · อนุมัติแล้ว · เสร็จสิ้น
- **สถานะแผนเดินทาง:** รออนุมัติ · ส่งกลับแก้ไข · ดำเนินการ (อนุมัติแล้ว) · รออนุมัติปิดงาน · ปิดงานแล้ว
- แก้ไข/ลบแผนเดินทางได้เฉพาะตอนรออนุมัติหรือส่งกลับแก้ไข (อนุมัติแล้วแก้ไม่ได้ ต้องสร้างแผนเดินทางใหม่สำหรับคันที่เหลือ)

## Scope ของ branch `feature/create-inspection`
- **กบค.:** รายการแผน, สร้าง/แก้ไข/ลบแผน, เลือกยานพาหนะเข้าแผน, ดูรายละเอียดแผน + พิจารณาเอกสาร ปจ.2 รายคัน

  - อัปโหลดเอกสารรายคัน แล้วส่งอนุมัติ
  - ถ้าถูกส่งกลับ แก้แล้วส่งใหม่
- **ขั้นอื่นของ flow** (อนุมัติแผน, แผนเดินทาง, บันทึกผล, ปิดแผน, ทะเบียน ปจ.2) เป็นงานของพี่นุ

## Business rules (ที่ทำในต้นแบบ)
- **ฟอร์มสร้างแผน**
  - แบ่ง 2 section: **ข้อมูลแผน** (ชื่อแผน, รอบตรวจ) · **ยานพาหนะในแผน**
  - ~~section ข้อมูลผู้รับจ้าง~~ ย้ายไปอยู่ที่แผนเดินทางแล้ว (20 พ.ย. 2569)
  - เดือนสิ้นสุดต้องไม่ก่อนเดือนเริ่มต้น
  - ต้องมียานพาหนะอย่างน้อย 1 คัน
- **ผู้รับจ้าง:** **1 แผนเดินทาง = ผู้รับจ้าง 1 ราย** · 1 แผนมีหลายแผนเดินทาง จ้างคนละรายได้ (เดิม 1 แผน = 1 ราย)
- **ตัวกรองหน้ารายการของ กบค.:** สถานะ (ผู้รับจ้างเอาออก เพราะย้ายไปอยู่ที่แผนเดินทาง)
- **popup เลือกยานพาหนะ**
  - แสดงเฉพาะประเภท 09
  - ยานพาหนะที่ไม่พร้อมใช้งาน เลือกได้ แต่มีคำเตือน
  - ยานพาหนะที่อยู่ในแผนอื่นที่ยังไม่ปิด เลือกไม่ได้
- **แก้ไข/ลบแผน:** ได้เฉพาะแผนที่ "รออนุมัติ" หรือ "ส่งกลับแก้ไข" แผนที่อนุมัติแล้วแก้หรือลบไม่ได้
- **หัวหน้า กบค. (บทบาทใหม่ 20 พ.ย. 2569):**
  - อนุมัติแผนที่ กบค. ส่งมา (ติ๊กหลายแผนแล้วอนุมัติพร้อมกันได้) หรือส่งกลับแก้ไขพร้อมเหตุผล
  - อนุมัติแล้ว กบค. สร้างแผนเดินทางได้ · ผู้รับจ้างเห็นงานเมื่อถูกใส่ในแผนเดินทาง
  - ~~อนุมัติปิดงาน / ไม่อนุมัติปิดงาน~~ ยกเลิก (20 พ.ย. 2569) ไม่มีปิดแผนหลัก
  - รายชื่อหัวหน้า กบค. ตอนนี้เป็นข้อมูลจำลอง 2 คน (ยังไม่รู้ว่ามีใครบ้าง)
- **ปิดงานแผนเดินทาง:** ผู้รับจ้างขอปิดได้เมื่อผลตรวจอนุมัติครบทุกคันของแผนเดินทาง · หน้าแผนเดินทางแสดงสรุปผ่าน/ไม่ผ่าน/ระงับ/ตรวจไม่ได้ + ค่าจ้างรวมเทียบงบ
- ~~สถานะแผน: รออนุมัติปิดงาน → ปิดงานแล้ว~~ ดูหัวข้อ Flow ปัจจุบัน
- **Flow ผู้รับจ้าง (เจ้าของงาน 20 พ.ย. 2569):**
  1. กบค. สร้างแผน
  2. ~~ผู้รับจ้างเห็นแผนทันที~~ → ผู้รับจ้างเห็นแผนหลังหัวหน้า กบค. อนุมัติ
  3. ผู้รับจ้างระบุข้อมูลและอัปโหลดเอกสาร
  4. ผู้รับจ้างกดส่งอนุมัติหา กบค.
  5. กบค. อนุมัติ หรือส่งกลับ
     - อนุมัติ = จบ
     - ไม่อนุมัติ = ผู้รับจ้างแก้แล้วส่งใหม่ วนจนกว่าจะอนุมัติ
- **กันงานผู้รับจ้างหาย:** คันที่มีผลตรวจแล้วเอาออกจากแผนไม่ได้ และเปลี่ยนผู้รับจ้างไม่ได้ถ้ามีผลแล้ว
- **ค่าจ้าง:**
  - กบค. กำหนด **ค่าจ้างตรวจของยานพาหนะแต่ละคัน** ในตารางยานพาหนะ**ของแผนเดินทาง** (ต้องครบทุกคันก่อนบันทึก · เดิมอยู่ที่แผน)
    - พิมพ์ในช่องของตารางได้เลย หรือติ๊กหลายคันแล้วใส่ค่าเดียวกันพร้อมกัน
- **ช่องเงินทุกช่อง:** พิมพ์ได้เฉพาะตัวเลขกับจุด 1 จุด · ออกจากช่องแล้วจัดรูปเป็น 9,000.00 (มี , หลักพัน · ทศนิยม 2 ตำแหน่งเสมอ · ไม่ใส่ = .00 · ขาด = เติม 0 · เกิน = ปัดเป็น 2 ตำแหน่ง)
    - งบรวม = ผลรวมรายคัน
  - ผู้รับจ้างเห็นค่าตามสัญญาเป็นค่าตั้งต้น แก้ได้ แต่ถ้าต่างจากสัญญาต้องใส่เหตุผล
  - กบค. เห็นป้าย "ต่างจากสัญญา"
- ~~ปีงบประมาณ~~ ตัดออกแล้ว (20 พ.ย. 2569) · เดือนสิ้นสุดแค่ต้องไม่ก่อนเดือนเริ่มต้น
- **ชื่อแผน:** เติมให้อัตโนมัติจากรอบตรวจ จนกว่าจะพิมพ์เอง
- **หน้าเลือกยานพาหนะ:**
  - ตัวกรอง (สังกัด, ครบกำหนดตรวจ, วาระ, ประเภท) อยู่ใต้ช่องค้นหาในตัว popup ไม่เปิดแผงซ้อน popup
  - เลือกแล้วกรองทันที และมีปุ่มล้างตัวกรอง
  - ตั้งตัวกรอง "ครบกำหนดในรอบนี้" + "เกินกำหนด" ให้ตั้งแต่เปิด
- **วันที่ตรวจ:** เลือกได้ทุกวันจนถึงวันนี้ ไม่ล็อก ไม่มีคำเตือนนอกรอบตรวจ
- **กบค. อนุมัติหลายคันพร้อมกัน:** ติ๊กคันที่รออนุมัติ แล้วกด "อนุมัติ (n คัน)"
- **เงื่อนไขอัปโหลด** (ใช้ตามนี้เสมอจนกว่าจะสั่งเปลี่ยน)
  - PDF, PNG, JPG
  - ไฟล์ละไม่เกิน 10 MB
  - ต่อคันอย่างน้อย 1 ไฟล์ ไม่เกิน 10 ไฟล์
- **ผู้รับจ้างบันทึกผลตรวจรายคัน** (อิง prototype พี่มิก หน้า "ผลการตรวจ ปจ.2")
  - ต้องกรอก: วันที่ตรวจ, ค่าจ้างตรวจคันนี้ (บาท), ผลการตรวจ (ผ่าน / ไม่ผ่าน / ระงับ / ตรวจไม่ได้), เอกสารการตรวจ ปจ.2
  - ตรวจไม่ได้: ต้องระบุเหตุผล และแนบหนังสือรับรองจากผู้แทนหน่วยงาน แทนเอกสาร ปจ.2
  - ข้อความบอกผลที่จะเกิด:
    - ผ่าน = ครบกำหนดถัดไป = วันที่ตรวจ + วาระ
    - ไม่ผ่าน / ระงับ = แจ้งผู้ดูแลยานพาหนะให้เปิดงานซ่อม
    - ตรวจไม่ได้ = คงวันครบกำหนดเดิม
  - หน้ารายละเอียดแผนของ กบค. แสดงค่าจ้างตรวจรวมของคันที่ส่งแล้ว
- **สถานะผลตรวจรายคัน**
  - ยังไม่บันทึกผล → กรอกยังไม่ครบ → พร้อมส่ง → รอ กบค. อนุมัติ (ล็อก)
  - จากรอ กบค. อนุมัติ ไปได้ 2 ทาง:
    - **อนุมัติแล้ว** (ล็อกถาวร)
    - **ส่งกลับแก้ไข** (ปลดล็อก ผู้รับจ้างอัปโหลดใหม่แล้วส่งอีกครั้ง)
- **ส่งอนุมัติ:** ปุ่มเดียว ส่งทุกคันที่กรอกครบและแก้ได้อยู่ โดยมีหน้าต่างยืนยันก่อน
