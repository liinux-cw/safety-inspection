# Scope ฝั่ง กบค. รายหน้าจอ (Safety Inspection · แผนตรวจ ปจ.2)

**บทบาทในส่วนของคุณ:** กบค. (ผู้สร้างแผน/พิจารณาผล) และ **หัวหน้า กบค.** (ผู้อนุมัติแผน/ปิดแผน)
**ไม่อยู่ใน scope:** หน้าของผู้รับจ้าง (พี่นุ) · แผนเดินทาง · notification

**สัญลักษณ์:** ✅ ทำแล้ว · 🔧 ต้องแก้ · 🆕 ยังไม่ได้ทำ

---

## หน้า 1 · รายการแผนตรวจ ปจ.2 (กบค.) ✅
**เข้าจาก:** เมนู Safety Inspection › แผนตรวจ ปจ.2

**แสดงผล:** ตาราง 1 แถว = 1 แผน
| คอลัมน์ | ข้อมูล |
|---|---|
| เลขที่ MR | เช่น MRZ7000010 |
| ชื่อแผน | + ปีงบประมาณ (บรรทัดรอง) |
| รอบตรวจ | ช่วงเดือน เช่น ธ.ค. 2569 – ก.พ. 2570 |
| ผู้รับจ้าง | ชื่อบริษัท |
| ยานพาหนะ | จำนวนคัน |
| ผลตรวจ ปจ.2 | อนุมัติแล้ว x/n คัน + รออนุมัติ y คัน |
| สถานะ | รอหัวหน้าอนุมัติ · ส่งกลับแก้ไข · อนุมัติแล้ว · รออนุมัติปิดงาน 🆕 · ปิดงานแล้ว |

**Action:**
- ค้นหาด้วยเลขที่ MR / ชื่อแผน
- ตัวกรอง (แผงด้านขวา): สถานะ · ผู้รับจ้าง
- ปุ่ม **"สร้างแผนตรวจ ปจ.2"**
- เมนู "…" ท้ายแถว:
  - ดูรายละเอียด
  - แก้ไข / ลบ (เฉพาะแผนที่ยังไม่อนุมัติ)
- ไม่มีแผน = หน้าว่าง + ปุ่มสร้างแผน · ค้นหาไม่เจอ = "ไม่พบข้อมูล" + ล้างตัวกรอง
- มือถือ: ตารางเป็นการ์ด มีไอคอนดู/แก้ไข/ลบบนการ์ด

## หน้า 2 · สร้าง / แก้ไขแผน (กบค.) ✅
### ส่วน A · ข้อมูลแผน
| ช่อง | วิธีกรอก | กฎ |
|---|---|---|
| ชื่อแผน | พิมพ์ | ระบบเติมให้จากรอบตรวจจนกว่าจะพิมพ์เอง · บังคับ |
| ปีงบประมาณ | อ่านอย่างเดียว | คิดจากเดือนเริ่มต้น (ปีงบ ต.ค.–ก.ย.) |
| รอบตรวจ: เดือนเริ่มต้น | dropdown | บังคับ |
| รอบตรวจ: เดือนสิ้นสุด | dropdown | ต้องอยู่ปีงบเดียวกันและไม่ก่อนเดือนเริ่ม |

### ส่วน B · ข้อมูลผู้รับจ้าง
| ช่อง | วิธีกรอก | กฎ |
|---|---|---|
| ผู้รับจ้าง | dropdown | บังคับ · 1 แผน = 1 ผู้รับจ้าง · เปลี่ยนไม่ได้ถ้าผู้รับจ้างบันทึกผลแล้ว |
| เบอร์โทรผู้รับจ้าง | ดึงอัตโนมัติ แก้ได้ | บังคับ |
| เลขที่สัญญา/ใบสั่งจ้าง | พิมพ์ | ไม่บังคับ |

### ส่วน C · ยานพาหนะในแผน
- **หัวตาราง:** จำนวนคัน · งบรวม (ผลรวมค่าจ้างทุกคัน)
- **ตาราง:**
  - คอลัมน์: ช่องติ๊ก · ทะเบียน (+รหัส·ประเภท) · สังกัด · ผู้ครอบครอง/เบอร์ · วาระ · ครบกำหนดตรวจ (+อีกกี่วัน/เกินกำหนด) · **ค่าจ้างตรวจ (ช่องพิมพ์)** · ปุ่มเอาออก
  - ช่องค่าจ้าง: รับแค่ตัวเลข · ออกจากช่องแล้วจัดรูปเป็น 9,000.00
- **Action:**
  - ค้นหาในตาราง
  - **"เพิ่มยานพาหนะ"** → เปิดหน้าต่างเลือกยานพาหนะ (หน้า 2.1)
  - ติ๊กหลายคัน → **"กำหนดค่าจ้าง (n คัน)"** ใส่ค่าเดียวกันพร้อมกัน
  - เอาออกทีละคัน (คันที่มีผลตรวจแล้วเอาออกไม่ได้)
- ยังไม่กำหนดค่าจ้างครบ = มีคำเตือน

### ปุ่มล่าง
- **ย้อนกลับ / ยกเลิก:** ถ้ามีข้อมูลค้าง จะถามยืนยันก่อนออก
- **"บันทึกและส่งอนุมัติ":** กดได้เมื่อกรอกครบ + มียานพาหนะ ≥ 1 คัน + ค่าจ้างครบทุกคัน
  - ✅ ส่งไปให้**หัวหน้า กบค.** อนุมัติ
- แผนถูกส่งกลับ = มีแถบแจ้งเหตุผลจากหัวหน้า กบค. ด้านบน

### หน้า 2.1 · หน้าต่างเลือกยานพาหนะเข้าแผน ✅
- **แสดง:** เฉพาะยานพาหนะประเภท 09 ที่ต้องตรวจ ปจ.2
- **คอลัมน์:** ทะเบียน · สังกัด · ผู้ครอบครอง/เบอร์ · สถานะยานพาหนะ · วาระ · ครบกำหนดตรวจ (+ป้าย "ครบกำหนดในรอบนี้")
- **ค้นหา:** ทะเบียน / รหัส / สังกัด
- **ตัวกรองใต้ช่องค้นหา** (เลือกแล้วกรองทันที):
  - ตัวกรอง: สังกัด · ครบกำหนดตรวจ · วาระ · ประเภทยานพาหนะ
  - เปิดมาจะตั้ง "ครบกำหนดในรอบนี้ + เกินกำหนด" ไว้ให้
  - มีปุ่มล้างตัวกรอง
- **กฎ:**
  - คันที่อยู่ในแผนอื่นที่ยังไม่ปิด = แสดงแต่ติ๊กไม่ได้ ("อยู่ในแผน MRZ… ที่ยังไม่ปิด")
  - คันที่ไม่พร้อมใช้งาน = เลือกได้ แต่เตือน "อาจตรวจไม่ได้"
- **Action:** ติ๊ก (ติ๊กทั้งหมดได้) → "เพิ่ม n คันเข้าแผน" · แบ่งหน้าละ 10

## หน้า 3 · รายละเอียดแผน (กบค.) ✅
**แสดงผล:**
- **หัว:** ชื่อแผน · เลขที่ MR · ปุ่มแก้ไข/ลบ (เฉพาะแผนที่ยังไม่อนุมัติ)
- **กล่องข้อมูลแผน:** เลขที่ MR · ชื่อแผน · ปีงบ · รอบตรวจ · จำนวนยานพาหนะ · สถานะ
- **กล่องข้อมูลผู้รับจ้าง:** ชื่อ · เบอร์ · เลขที่สัญญา · งบรวมตามสัญญา · ค่าจ้างรวมที่ส่งแล้ว
- **ตารางผลตรวจรายคัน:** ทะเบียน · สังกัด · ครบกำหนด · วันที่ตรวจ · ผล (ผ่าน/ไม่ผ่าน/ระงับ/ตรวจไม่ได้) · ค่าจ้าง (+ป้ายต่างจากสัญญา) · สถานะ (ยังไม่บันทึก/รอ กบค. อนุมัติ/อนุมัติแล้ว/ส่งกลับแก้ไข)

**Action:**
- แถบแจ้ง "มีผลรออนุมัติ n คัน"
- **พิจารณาทีละคัน** (หน้า 3.1)
- **ติ๊กหลายคัน → "อนุมัติ (n คัน)"** + ยืนยัน
- ดูผลของคันที่อนุมัติแล้ว (อ่านอย่างเดียว ดาวน์โหลดเอกสารได้)
- ✅ ปุ่ม **"สรุปปิดงาน"** → หน้า 4 (เมื่อแผนอนุมัติแล้ว) · แถบสถานะ (รอหัวหน้าอนุมัติ / ส่งกลับ / รออนุมัติปิดงาน / ปิดงานแล้ว)

### หน้า 3.1 · หน้าต่างพิจารณาผลตรวจ ✅
- **แสดง:**
  - วันที่ตรวจ · ค่าจ้าง (เทียบสัญญา + เหตุผลถ้าต่าง) · ผลการตรวจ · ครบกำหนดเดิม
  - เหตุผลที่ตรวจไม่ได้ (ถ้ามี) · คำเตือนถ้าวันที่ตรวจอยู่นอกรอบ
  - เอกสาร ปจ.2 / หนังสือรับรอง (ดาวน์โหลดได้)
- **Action:**
  - เลือก **อนุมัติ** (ล็อกถาวร) หรือ **ส่งกลับแก้ไข** (ต้องระบุเหตุผล)
  - กด "ยืนยันผลการพิจารณา"

## หน้า 4 · สรุปปิดงานแผน (กบค.) ✅
- **แสดง:**
  - เงื่อนไขปิดงาน: ผลอนุมัติครบทุกคัน (x/n)
  - สรุปจำนวน ผ่าน · ไม่ผ่าน · ระงับ · ตรวจไม่ได้
  - ค่าจ้างตรวจรวม เทียบกับงบตามสัญญา
- **Action:**
  - **"ขออนุมัติปิดงาน"** กดได้เมื่อครบเงื่อนไข → popup เลือกหัวหน้า กบค. ผู้อนุมัติ (เลือกใหม่ได้) + หมายเหตุ (ถ้ามี) → สถานะ "รออนุมัติปิดงาน"

## หน้า 5 · หัวหน้า กบค.: แผนรออนุมัติ ✅
**เข้าจาก:** เมนู Safety Inspection › แผนรออนุมัติ (เห็นเฉพาะบทบาทหัวหน้า กบค.)

**แสดง:** แท็บ
- **รออนุมัติแผน:** แผนที่ กบค. ส่งมา
- **รออนุมัติปิดงาน:** แผนที่ขอปิดงาน
- **ดำเนินการแล้ว:** ประวัติ

แต่ละแถว: เลขที่ MR · ชื่อแผน · รอบตรวจ · ผู้รับจ้าง · จำนวนคัน · งบรวม · วันที่ส่ง

**Action:** ติ๊กหลายแผน → "อนุมัติแผน (n)" / "อนุมัติปิดงาน (n)" + ยืนยัน · เปิดรายละเอียด (หน้า 5.1) · เมนูมี Badge จำนวนที่รอ

### หน้า 5.1 · รายละเอียดเพื่ออนุมัติ ✅
- **แสดง:** ข้อมูลแผน · ข้อมูลผู้รับจ้าง · ตารางยานพาหนะ + ค่าจ้าง (อ่านอย่างเดียว) · (ถ้าเป็นคำขอปิดงาน: สรุปผลแบบหน้า 4)
- **Action:**
  - เลือก **อนุมัติ** / **ส่งกลับแก้ไข** (ต้องมีเหตุผล) → ยืนยัน
  - อนุมัติแผน → ผู้รับจ้างเห็นแผนและเริ่มงานได้
  - อนุมัติปิดงาน → แผน "ปิดงานแล้ว" และทะเบียน ปจ.2 อัปเดต
  - ส่งกลับ → กลับไปให้ กบค. แก้แล้วส่งใหม่

## หน้า 6 · ทะเบียน ปจ.2 🆕
**เข้าจาก:** เมนู Safety Inspection › ทะเบียน ปจ.2

**แสดง:** ยานพาหนะประเภท 09 ทุกคัน
- คอลัมน์: ทะเบียน · ประเภท · สังกัด · ผู้ครอบครอง · ตรวจล่าสุด · ผล · ครบกำหนดครั้งถัดไป (+เกินกำหนด/อีกกี่วัน) · อยู่ในแผน (MRZ… / ไม่อยู่ในแผน)

**อัปเดตเองเมื่อ กบค. อนุมัติผล:**
- ผ่าน = วันที่ตรวจ + วาระ
- ไม่ผ่าน/ระงับ = บันทึกผล
- ตรวจไม่ได้ = คงวันครบกำหนดเดิม

**Action:**
- ค้นหา
- ตัวกรอง: สังกัด · ผล · ครบกำหนด · อยู่ในแผนหรือไม่
- ดูประวัติ/เอกสารของคันนั้น
- **อัปโหลดผลนอกแผน:** เฉพาะคันที่ไม่อยู่ในแผนใด (ตรวจรายคัน/นอกแผน)
